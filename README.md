# JP Trip Plexy MVP

Семейный русскоязычный путеводитель по Токио для локального запуска.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

## Содержимое MVP

- Наша поездка и трансферы
- Осиагэ/Сумида, Асакуса, Уэно, Сибуя, Синдзюку
- История и культура районов
- Правила поведения в Японии
- Tokyo Disneyland
- Лайфхаки и разговорник

Информация о ценах, расписании, ресторанах и халяльном статусе требует проверки перед поездкой.
